# Instagram-завод для репетитора русского языка

**Продолжение в облаке:** [CLOUD-HANDOFF.md](CLOUD-HANDOFF.md) — текущий результат,
контекст, референсы и команды запуска. [Готовый пилот](outputs/pilot-2026-09-12/index.html)
и [все слайды](outputs/pilot-2026-09-12/contact-sheet.jpg). Для настройки среды:
`bash .codex/setup.sh`. Пилот пока не опубликован в Instagram.

Набор для ведения Instagram-аккаунта репетитора: сайт-визитка, система рубрик,
банк тем и генератор контент-плана.

## Что внутри

| Файл | Что это |
|---|---|
| `index.html` | Сайт-визитка для ссылки в шапке профиля: услуги, цены, отзывы, FAQ, кнопки записи |
| `factory.js` | Генератор контент-плана: раскладывает рубрики и темы по датам публикаций |
| `content/rubrics.json` | 7 рубрик с весами, структурой и советами по производству |
| `content/topics.json` | Банк из ~90 готовых тем по рубрикам — дописывайте свои |
| `content/templates.md` | Шаблоны подписей и каруселей под каждую рубрику |
| `content/plan.md` / `plan.json` | Сгенерированный план (появляются после запуска) |

## Как пользоваться

### 1. Сайт-визитка

Откройте `index.html` и замените всё, что помечено `✏️ ЗАМЕНИТЬ`:
имя, описание, телефон в ссылках WhatsApp/Telegram, цены, отзывы.
Фото положите рядом с файлом под именем `photo.jpg`.
Разместить можно на GitHub Pages, Netlify или любом хостинге — это один файл без зависимостей.

### 2. Контент-план

```bash
node factory.js              # план на 4 недели с сегодняшнего дня
node factory.js 2            # на 2 недели
node factory.js 4 2026-09-01 # на 4 недели с 1 сентября
```

Получите `content/plan.md`: таблица «дата → рубрика → тема», список Reels для
съёмочного дня и чек-лист перед публикацией. Использованные темы запоминаются
в `content/used-topics.json` и не повторяются, пока банк не закончится.

### 3. Тексты

Для каждой позиции плана откройте `content/templates.md`, найдите шаблон рубрики
и подставьте тему. Один пост — 10–15 минут работы.

### Ритм публикаций

По указанию автора от 14 сентября 2026: **одна публикация ежедневно, семь в неделю**, включая выходные. В дневном слоте — пост, карусель или Reels; после подтверждённого выпуска требуется полный Stories-репост.

Облачный запуск уже настроен на 17:50 МСК с ориентиром около 18:00; фактическое время зависит от очереди GitHub Actions. Генератор планирует все семь дней. Публикация требует одобрения, наступившей даты и полной проверенной сборки. Старый материал без сборки не блокирует другой готовый материал и не пересобирается автоматически. Если готовых материалов нет, ежедневный выпуск остаётся заблокированным; одно расписание не подтверждает публикации.

## Подключение Instagram к Claude

Через коннектор Windsor.ai можно подтягивать статистику аккаунта и публиковать
посты прямо из чата с Claude. Требования: аккаунт Instagram должен быть
Business или Creator и привязан к странице Facebook. Подключение — по ссылке,
которую Claude выдаёт в чате (Windsor.ai → Instagram → Authorize).

## Фабрика контента: очередь с одобрением

Посты проходят через `content/queue.json` со статусами
`pending` → `approved` → `published`.

```bash
node render.js          # отрисовать слайды и пересобрать превью
node render.js <id>     # отрисовать один пост
```

Скрипт делает:
- `content/images/<id>-N.jpg` — слайды 1080×1350 (4:5, подходит и для ленты, и для Graph API);
- `content/preview.html` — страница одобрения со всеми постами; картинки вшиты в неё
  как data URI, поэтому файл можно открыть с телефона или опубликовать как артефакт.

Цикл работы: Claude пишет посты в очередь → `node render.js` → вы смотрите превью и
говорите, что одобряете → Claude меняет статус на `approved` → публикация.

Оформление слайдов задаётся в `render.js` (константа `PALETTE` и функция `slideHtml`).
