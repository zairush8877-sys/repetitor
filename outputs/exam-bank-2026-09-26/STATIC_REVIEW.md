# Просмотр галереи локальным файлом

Откройте `index.html` в файловой панели Codex с предпросмотром HTML либо как
локальный файл в браузере. Сервер запускать не требуется. Если браузер принимает
адрес файла, используйте:

```text
file:///Users/zi/.codex/worktrees/63e6/мама%20инста/outputs/exam-bank-2026-09-26/index.html
```

Относительные адреса `content/...` и `standalone-stories/...` разрешаются относительно
этого `index.html`. При переносе сохраняйте структуру папки и корневую папку
`assets/photos/exam-v1`, если нужны резервные иллюстрации. Не копируйте только HTML
в отдельное место без медиа. Проверка относительных `file:`-адресов выполнена
статически; результат в `gallery-static-review.json`.

## Что проверить при ручном просмотре

1. На широком окне выпуски размещены в двух колонках, на узком — в одной;
   текст и элементы управления помещаются по ширине.
2. Фильтры показывают 14 / 7 / 7 / 8 / 6 выпусков соответственно:
   все, ЕГЭ, ОГЭ, Reels, карусели.
3. Reels запускается кнопкой воспроизведения. У карусели доступны четыре видео,
   листание пальцем и стрелками. Звук включается только после действия пользователя;
   старт следующего видео останавливает предыдущее.
4. Раздел репоста Stories раскрывает один полный кадр-анонс Reels либо все четыре
   слайда карусели по порядку. Кадры вписаны целиком; по нажатию открываются крупнее.
5. Следующий раздел «Истории дня: вопрос и разбор» содержит два видео с настоящими
   постерами: первый вопрос, затем полное объяснение. Комплект помечен как черновик
   без назначенного дня. Закрытие раздела останавливает воспроизведение.
6. Видны композитор, исполнитель и короткая музыкальная справка. В раскрытой подписи
   читается полный текст; копирование включает музыкальные кредиты. В обычном
   `file:`-контексте используется резервное копирование, если Clipboard API недоступен.
7. Указанные даты остаются предложенным планом; на странице нет утверждения,
   что публикации уже вышли.

Если панель показывает исходный код вместо HTML, открыть этот же файл в браузере
как локальный документ. Ограничение текущей среды на HTTP-сервер не обходить
прокси, удалённой загрузкой или заменой сетевого адреса.

Эти пункты — инструкция для визуального просмотра. Автоматическая статическая
проверка структуры и наличия файлов не объявляется браузерной проверкой.
