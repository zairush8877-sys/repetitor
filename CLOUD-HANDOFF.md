## Готовый пилот

Тема: **«Одни буквы — разные слова»**.
Пары: **а́тлас / атла́с**, **и́рис / ири́с**, **хло́пок / хлопо́к**.
Обе формы правильные, поэтому здесь нет крестиков и зачёркивания «ошибок».
У `ири́с` толкование «сорт конфет». Итоговая строка: «три пары — шесть слов».

Папка `outputs/pilot-2026-09-12/` содержит:

- `index.html` — галерея с четырьмя вкладками;
- `contact-sheet.jpg` — все шесть слайдов;
- `content/images/` — шесть JPG 1080×1350 и шесть MP4 со звуком по 6 секунд;
- `content/reels/` — альтернативный Reels 1080×1920, 14,6 секунды, и полная обложка;
- `content/reposts/` — семь полных JPG 1080×1920: шесть слайдов и анонс Reels;
- `captions.txt` — две подписи с музыкальными кредитами;
- `editorial/` — стратегия, тексты, словарные источники и финальная редактура;
- `content/prepared/index.json` — проверяемые метаданные сборки;
- `result.json`, `verification.json`, `design/layout-check.json` — результаты проверок.

Карусель и Reels — **две версии одного выпуска**, не два поста подряд.
Оба черновика имеют статус `pending`, без даты. Школьная тема подана для совместного
чтения родителя с ребёнком; при выборе даты учитывать ограничение одной школьной
единицы в неделю. Даты не назначены специально для устранения предупреждений теста.

Музыка: Kevin MacLeod, Carefree / Easy Lemon, CC BY 4.0, кредиты и источники в
`content/music/index.json`. Это проверенные локальные дорожки, не подтверждённые
тренды Instagram. JPG сам по себе не содержит звук. Происхождение фотографий —
`assets/photos/index.json` и `assets/photos/paper-collage.json`.

## Подготовка Linux-окружения

Использовать Node.js 22 или новее. Включённого доступа в интернет недостаточно
для рендера: нужны также Chromium и FFmpeg. Готовый скрипт:

```bash
bash .codex/setup.sh
```

Он ставит npm-зависимости, Chromium с системными библиотеками и ffprobe.
Не использует Instagram, не изменяет очереди и не публикует контент.
Его можно указать в ручном скрипте установки окружения или выполнить в первой задаче.
Если npm/Chromium уже установлены автоматически, повторный запуск допустим.

## Проверка перенесённого пилота

Из корня проекта, в одной shell-сессии:

```bash
export MEDIA_CONTENT_DIR="$PWD/outputs/pilot-2026-09-12/content"
node publish.js --validate-prepared
node check-content.js 2026-09-12-omographs-carousel
node check-content.js 2026-09-12-omographs-reel
node scripts/verify-paper-pilot.js
```

`--validate-prepared` проверяет файлы локально, без токена и вызовов Instagram.
Предупреждение об отсутствии даты ожидаемо; это ещё не план публикаций.
Для локального просмотра можно запустить `python3 -m http.server 8000` из корня
и открыть `/outputs/pilot-2026-09-12/index.html` средствами облачной задачи.

Пересборка по необходимости:

```bash
node build-media.js 2026-09-12-omographs-carousel 2026-09-12-omographs-reel
node scripts/preview-paper-pilot.js
node scripts/package-paper-pilot.js
node scripts/verify-paper-pilot.js
```

Для новой темы использовать новую изолированную папку и `MEDIA_CONTENT_DIR`.
Автоматический процесс `.claude/workflows/post-factory.js` относится к прежнему
окружению Claude. Если Workflow tool отсутствует, не утверждать, что он выполнен:
провести роли стратега, копирайтера, корректора и редактора доступными средствами,
сохранив результаты в `editorial/`. Словарную проверку по источникам не пропускать.
