# Токен Instagram API для автопубликации

Проверенный маршрут получения токена, которым можно публиковать посты и карусели
в Instagram и читать статистику аккаунта. Собран по итогам реального подключения,
где три очевидных пути оказались тупиковыми.

## Где всё делается

**Business Manager — единственная точка входа.** Не консоль разработчика,
не настройки Instagram, не Центр аккаунтов. Всё управление живёт здесь:

| Что | Ссылка |
|---|---|
| Главная Business Suite | `business.facebook.com` |
| Настройки бизнес-портфолио | `business.facebook.com/latest/settings` |
| **Системные пользователи** (токены) | `business.facebook.com/latest/settings/system_users` |
| Аккаунты Instagram | `business.facebook.com/latest/settings/instagram_account` |
| Страницы Facebook | `business.facebook.com/latest/settings/pages` |
| Приложения | `business.facebook.com/latest/settings/apps` |
| Люди и роли | `business.facebook.com/latest/settings/business_users` |
| Планировщик публикаций | `business.facebook.com/latest/planner` |
| Статистика | `business.facebook.com/latest/insights` |
| Входящие (Direct и комментарии) | `business.facebook.com/latest/inbox` |

К ссылке можно добавить `?business_id=<ID>`, если портфолио несколько.

Приложение создаётся один раз на `developers.facebook.com/apps` — дальше туда
заходить не нужно, кроме случая, когда требуется добавить новое разрешение
(«Сценарии использования» → «Разрешения и функции»).

## Главное: начинать сразу с системного пользователя

**Рабочий путь — токен системного пользователя в Business Manager.** Он не зависит
от личных настроек приватности Instagram-аккаунта, не протухает и выдаётся без
всплывающих окон авторизации.

Три пути, которые выглядят проще, но чаще всего упираются в стену:

| Путь | Чем заканчивается |
|---|---|
| Сторонние сервисы (Windsor.ai и подобные) | Публикуют только одиночные картинки, без каруселей и Reels. Платные после пробного периода |
| «Настройка API для входа в Instagram» → «Сгенерировать маркер» | `OAuthException: Будущие действия вашего аккаунта вне платформ Meta выключены`. Не лечится настройками приватности, даже когда они выставлены верно |
| Graph API Explorer | По умолчанию подставляет **маркер приложения** (`appid|secret`), а не пользовательский. Нужных разрешений часто нет в списке |

## Порядок действий

### 1. Профессиональный аккаунт Instagram

Настройки → Тип аккаунта и инструменты → переключить на **Business** или **Creator**.
Личный аккаунт к API не подключить.

### 2. Приложение в Meta for Developers

`developers.facebook.com/apps` → «Создать приложение»:

- сценарий использования: **«Управление сообщениями и контентом»** (иконка Instagram)
- тип: **Бизнес**
- привязать к бизнес-портфолио, которому принадлежит аккаунт Instagram

Приложение остаётся в режиме разработки — для своего аккаунта публикация работает,
проверка Meta (App Review) не нужна.

### 3. Разрешения приложения

«Сценарии использования» → «Разрешения и функции». Добавить как минимум
`instagram_business_content_publish` — без него публикации не будет.

Осторожно: в списке есть похожие пары (`instagram_content_publish` и
`instagram_business_content_publish`). Первое — для схемы со входом через Facebook,
второе — для входа через Instagram. Нужны оба, если пробуете разные пути.

### 4. Instagram в бизнес-портфолио

Business Manager → Настройки → Аккаунты → Аккаунты Instagram → добавить аккаунт.
Проверить, что в карточке аккаунта указан владелец — бизнес-портфолио, а не человек.
Это условие для следующего шага.

### 5. Системный пользователь и токен

Business Manager → Настройки → **Пользователи → Системные пользователи**:

1. «Добавить» → имя (например `autopost`) → роль **Администратор**
2. **«Назначить объекты»** — обязательно до генерации токена, иначе токен пустой:
   - вкладка «Приложения» → приложение → полный доступ
   - вкладка «Аккаунты Instagram» → аккаунт → полный доступ
   - вкладка «Страницы» → страница, если есть
3. **«Сгенерировать маркер»** → выбрать приложение → срок **бессрочный**
4. Разрешения — минимальный набор под задачу:

   | Разрешение | Зачем |
   |---|---|
   | `instagram_basic` | Читать профиль. Без него не работает ничего |
   | `instagram_content_publish` | Публикация постов и каруселей |
   | `instagram_manage_insights` | Статистика: охваты, вовлечённость |
   | `pages_show_list` | Найти привязанную страницу |
   | `business_management` | Доступ к аккаунту через бизнес-портфолио |

   Не отмечать: `catalog_management` (товарные каталоги),
   `instagram_branded_content_*`, `shopping_tag_products`.

   Отдельно про переписку — см. раздел ниже. По умолчанию не включать.

Токен показывают **один раз**.

Как выглядит правильно настроенный системный пользователь — в карточке
«Назначенные объекты» перечислены все три с пометкой «Полный доступ»:
страница Facebook, приложение, аккаунт Instagram. Если чего-то не хватает,
токен выпустится, но работать не будет.

### 6. Хранение токена

Только в переменной окружения (`IG_ACCESS_TOKEN`). Никогда — в репозиторий,
в чат и в скриншоты.

Если секрет или токен всё же попал в переписку или на картинку: приложение →
«Настройки приложения» → «Основное» → «Секрет приложения» → **«Сбросить»**;
токены системного пользователя отзываются кнопкой «Отозвать маркеры».

## Публикация

Эндпоинт: `https://graph.facebook.com/v23.0/{ig-user-id}/media` — для токена
системного пользователя (для токенов Instagram-входа домен другой:
`graph.instagram.com`).

Одиночный пост: создать контейнер (`image_url`, `caption`) → дождаться
`status_code: FINISHED` → опубликовать через `/media_publish`.

Карусель: создать контейнер на каждый слайд с `is_carousel_item=true` → собрать
родительский контейнер (`media_type=CAROUSEL`, `children=id1,id2,...`) → опубликовать.

Требования к картинкам: JPEG, до 8 МБ, соотношение сторон от 4:5 до 1.91:1,
доступны по публичной ссылке (Instagram скачивает их сам — локальные файлы
и приватные репозитории не подойдут).

Лимит: 50 публикаций за 24 часа. Reels и Stories через этот API не публикуются.

## Ответы на сообщения и комментарии

Отдельные разрешения, добавляются к токену тем же способом (перевыпустить токен
системного пользователя, отметив нужные пункты):

| Разрешение | Что даёт |
|---|---|
| `instagram_manage_messages` | Читать Direct и отвечать на сообщения |
| `instagram_manage_comments` | Читать комментарии, отвечать, скрывать, удалять |

Как работает: сообщения приходят через Webhooks (нужен публичный адрес для
обратного вызова и статус приложения «Опубликовано»), ответы отправляются на
`/{ig-user-id}/messages`. Ответ на комментарий — `POST /{comment-id}/replies`.
Окно ответа на сообщение — 24 часа с последнего сообщения пользователя.

**Правила, если автоматика получает доступ к переписке.** Здесь заканчивается
контент и начинается живое общение с людьми, поэтому:

1. **Не отвечать от лица человека без предупреждения.** Родитель пишет репетитору,
   а не роботу. Автоответ помечается как автоматический: «Это автоматический ответ,
   [имя] ответит лично в течение дня».
2. **Автоматизировать только шаблонное:** приветствие на первое сообщение,
   часы работы, цены, ссылку на запись. Всё, что требует решения — цена со скидкой,
   перенос занятия, конфликт, вопрос об успеваемости ребёнка — передавать человеку.
3. **Черновики вместо отправки.** Если нужны содержательные ответы — готовить
   черновики на одобрение, а не отправлять сразу. Тот же принцип, что с постами:
   `pending` → человек смотрит → отправка.
4. **Не трогать личные переписки.** Доступ выдаётся ради заявок от клиентов;
   читать и разбирать личное — за рамками задачи.
5. **Комментарии не удалять и не скрывать автоматически.** Даже грубые:
   это репутация владельца аккаунта, решение за ним.

Если планируется только автоответ на первое сообщение — проще и безопаснее
включить его в Meta Business Suite («Входящие» → «Автоматические ответы»),
без API и без токена с доступом к переписке.

## Разбор частых ошибок

**`OAuthException: Будущие действия вашего аккаунта вне платформ Meta выключены`** —
блок на стороне личного аккаунта Instagram. Настройка живёт в Центре аккаунтов
(«Ваша информация и разрешения» → «Действия, связанные с другими компаниями»),
но даже при верном значении ошибка часто остаётся. Не тратить время — идти
через системного пользователя.

**`Недостаточно прав для роли разработчика`** — аккаунту не назначена роль
тестировщика Instagram, либо приглашение не принято. Приглашение принимается
на `instagram.com/accounts/manage_access/` (в веб-версии, вкладка «Приглашения
тестировщика»), а не в мобильном приложении.

**Мамин/чужой аккаунт не виден в списке** — вход выполнен под не тем профилем.
Центр аккаунтов у каждого аккаунта свой; настройки одного не влияют на другой.

**`developers.facebook.com` не открывается, DNS-ошибка** — домен недоступен из сети
или не входит в списки обхода VPN. С мобильного интернета часто открывается.

**Кнопка генерации ничего не открывает** — браузер заблокировал всплывающее окно.
Значок блокировки в правом конце адресной строки → разрешить.

## Когда остановиться

Если после системного пользователя токен всё равно не получен — не продолжать.
Планировщик Meta Business Suite публикует карусели, Reels и Stories бесплатно,
поддерживает отложенные публикации и требует пяти минут на пост. Разница между
ним и API — только в том, кто нажимает кнопку. Это не стоит третьего дня борьбы.
