# Восстановление ежедневного выпуска

Пользователь разрешил подготовить недостающие материалы и запустить процесс.
Существующее расписание ежедневного выпуска сохранено: `50 14 * * *` UTC.
GitHub Actions может запускать задания позже указанного времени.

Причина пропуска: у четырёх старых approved-черновиков не было актуальных
подготовленных медиа. Семь запусков 12–18 сентября завершились ошибкой.
Старые черновики возвращены в pending для редакционной переработки.

## Банк

| Дата | Выпуск |
|---|---|
| 20.09 | Синяя коляска. Или ребёнок? |
| 21.09 | Он хочет учит(ь)ся — один школьный выпуск |
| 22.09 | Абонемент есть. Абонент не отвечает |
| 23.09 | «Досмотрю» не обещает «скоро» |
| 24.09 | Отправили письмо — стали адресантом |
| 25.09 | Образованный — ещё не значит вежливый |

Для каждого есть MP4 1080×1920 с AAC, итоговая обложка, полный Stories-анонс,
музыкальные кредиты, хеши и манифест. Экспорт выполнен Remotion в браузере.
Все 30 сцен и 6 Stories визуально просмотрены. Проверены длительности,
ненулевая аудиодорожка, prepared.validate, последовательный выбор по дням,
ESLint и TypeScript. Проверка контента пройдена с одним предупреждением:
пара абонент/абонемент похожа на школьную; здесь она подана как взрослое
бытовое словоупотребление, school=false сохранено после редакционной проверки.

Общая команда validate-prepared без ID также берёт старые pending-черновики
без сборки и поэтому не проходит. Новый банк проверяется по конкретным ID.
Это не препятствует выбору готовых approved-выпусков.

HyperFrames-композиция сохранена; линтер прошёл. Runtime/повторный экспорт
HyperFrames на Mac не подтверждены из-за ограничения Chromium sandbox.
Подробности и команды — `video-lab/README.md`.

Банк обеспечивает выпуск до 25 сентября включительно. Автоматического
создания новых тем после этой даты этот запуск не добавляет.
Галерея: `outputs/recovery-2026-09-19/index.html`.
