# Проект «мама инста»

Репозиторий: `zairush8877-sys/repetitor`, основная ветка `main`.
Это конвейер контента преподавателя русского языка Анны, Instagram `@mairova_a_a`.
Не путать с медицинским сайтом `mywebZV`, проектом «мой инстаграм» или репетитором Данаи.

Ритм для текущей серии изменён пользователем 31.10.2026: **15 Reels V3 с ретушью и музыкой, по одному через день**. Последняя команда «выложи завтра в 9 утра» перенесла первый выпуск на **1 ноября 2026, 09:00 МСК**. Активный календарь — `content/active-feed-campaign.json`: 1–29 ноября, целевой слот 09:00 МСК. GitHub может задерживать запуск; публикация разрешена только в дату слота, после 09:00 и до 22:00. В свободные дни и после завершения серии старая лента не подхватывается. Предыдущий режим 2–3 поста в день для ленты заменён этим календарём; старые одобрения и даты сохранены, но не участвуют в автоматическом выпуске. Полные подписи V3 уже содержат музыкальные кредиты. Обложки задаются отдельным `cover_url`. После выпуска выполняется полный Stories-репост: точная MP4-копия всего V3 с обработанным голосом, ретушью и музыкой. Неподвижная обложка не заменяет этот репост.

Один writer сохранён с прежней группой concurrency. Намерение и receipt ленты сохраняются в GitHub до/после `media_publish`; неизвестный результат блокирует автоматический повтор. Перед публикацией проверяются аккаунт, публичные SHA файлов и история Instagram.

В начале продолжения прочитать **CLOUD-HANDOFF.md**. Там итог предыдущей работы,
готовый пилот, команды для Linux и ограничения фактически выполненных проверок.
Общаться с пользователем по-русски, коротко и по шагам.

на эту папку. Не выполнять общий рендер старой рабочей очереди ради проверки переноса.

Разрешение на перенос файлов в GitHub не является разрешением на выпуск в Instagram.
Не менять одобрения, даты и расписания и не публиковать старые материалы автоматически.
Экспорт Stories и существование MP4 не доказывают публикацию в Instagram.
Не добавлять токены, cookie, `.env`, секреты Actions или данные браузера в репозиторий.

Референсы в `references/2026-09-11/` предназначены для разбора оформления.
